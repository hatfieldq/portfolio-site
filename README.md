# Portfolio — Quinnten Hatfield

Personal site sharing my work in RF signal processing, geolocation/tracking, and modeling — including interactive demos like a TDOA geolocation visualizer.

Built with Next.js (App Router), React, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Build

```bash
npm run build
```
